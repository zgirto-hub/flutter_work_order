# Data Model: HyDE Retrieval for Manual Assistant

**Date**: 2026-04-12 | **Branch**: `043-hyde-retrieval`

## Summary

No data model changes. The hypothetical document generated by HyDE is transient (in-memory only) and is discarded after embedding. No new database tables, columns, or migrations are required.

## Existing Entities (unchanged)

- **manuals**: Manual metadata (title, file info, upload info). No changes.
- **manual_chunks**: Chunked text with pgvector embeddings. No changes.
- **manual_corpus_stats**: Aggregate stats. No changes.
- **manual_assistant_settings**: System instructions, model config. No changes.

## Transient Data (new, not persisted)

- **Hypothetical Answer**: A 1-2 paragraph text generated by the LLM in response to the user's (possibly rewritten) query. Exists only in memory during the `ask()` call. Used solely as input to `embed_single()` to produce a vector for similarity search. Never stored, never returned to the user.
